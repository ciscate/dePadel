DE PADEL

Pagina web sobre una organizacion de Padel que realiza torneos y brinda servicios a sus jugadores. Se realizo de manera particular para un cliente, siguiendo todos los pasos en el desarrollo de la web, desde el contacto con el cliente, analisis de su negocio, presentacion de la idea general, presentacion de presupuesto detallado, desarrollo de la web con sus respectivos feedback, realizacion de pruebas unitarias, documentacion, alquiler de un servidor linux en la nube, configuracion del servidor, instalacion de certificados ssl del lado del cliente y del servidor. implementacion final del proyecto Se utilizo un stack tecnologico Backend de Java (POO) + SpringBoot (POC) + Mysql + Open api (ex Swagger) Se utilizo un stack tecnologico Frontend de HTML5 + CSS3 (Responsive Design)+ Javascript (Vanilla)
